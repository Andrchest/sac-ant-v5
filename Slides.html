Andrei PolevoiMethod05

Why SAC — and what else could be used

The objective SAC maximises — reward plus entropy
J(π) = Σ E[ r + α H(π) ]

Three properties that fit this task

Continuous actions
The policy outputs torques directly. Standard DQN is built for discrete choices.
Replay buffer
Off-policy: every collected transition is reused many times instead of discarded.
Entropy in the objective
The magenta term above. Its weight α is learned, not hand-tuned.
TD3
off-policy · deterministic

A deterministic policy plus Gaussian exploration noise, clipped double-Q, delayed policy updates and target smoothing. Same replay machinery, no entropy term.

PPO
on-policy · stochastic

A stochastic policy trained with a clipped surrogate objective on fresh rollouts. No replay reuse — each update consumes newly collected data.

Andrei PolevoiMethod06

Inside SAC — which networks exist

This is the set of networks, not a training loop. The next two slides show how each of them is updated.

Actorpolicy
π: s → (μ, log σ)
Produces the action distribution. The only network used when the agent acts.
Two criticstrained
Q_i: (s,a) → ℝ
Score an action. Both are regressed to the same target; the smaller score is used.
Two target criticsslow copies
θ′ ← τθ + (1−τ)θ′
Never trained by gradient. They follow the critics slowly and build the target.
Temperatureone scalar
α > 0
Learned alongside the networks. It sets how much entropy is worth in reward units.
Replay bufferstorage, not a network
D = {(s,a,r,s′,d)}
Past transitions, sampled in minibatches for every update.
Actinguses only the actor — critics, targets and buffer are idle.
Learningupdates critics, actor and α from buffer samples and the target copies.
Andrei PolevoiMethod07

How the critics learn

01
Sample the next action from the current actor
ε ~ N(0,I) → u′ = μ + σ⊙ε → a′ = tanh(u′)
Gaussian noise, then an affine transform, then tanh to stay inside the action bounds. No gradient flows into the actor here.
02
Build the soft target
y = r + γ(1−d)(min Q′ − α log π)
d = terminated. A time-limit truncation keeps the bootstrap; a real terminal state zeroes it.
03
Regress both critics to that target
L(θ_i) = (Q_i(s,a) − y)²
The target y is treated as a constant during the gradient step.
04
Move the target copies
θ′ ← τθ + (1−τ)θ′, τ = 0.005
Slow tracking is what keeps this regression stable.
Andrei PolevoiMethod08

How the actor learns

01
Sample a fresh action — reparameterised, so gradients pass through it
ε ~ N(0,I) → u = μ + σ⊙ε → ã = tanh(u)
Same three stages as before, but now the sample is differentiable with respect to φ.
02
Log-probability of the squashed action
log π(ã|s) = log N(u; μ, σ) − Σ log(1 − tanh²(u))
The sum is the tanh change-of-variables correction — without it the entropy term would be wrong.
03
Improve the policy — critics are frozen
L(φ) = α log π(ã|s) − min Q(s,ã)
Only φ moves: the policy trades value against entropy.
04
Adjust the temperature to hold the entropy target
L(α) = −α(log π + H̄), H̄ = −8
α rises when the policy becomes too deterministic, falls when it becomes too random.

Mikhail KrylovFindings17

Limitations of the algorithm itself

Continuous actions only
Discrete or hybrid spaces need a different formulation.
Replay memory
A million stored transitions costs gigabytes of RAM.
Reward-scale sensitive
α trades entropy against reward magnitude.
Heuristic entropy target
H̄ = −dim(A) is a rule of thumb.
Pessimistic values
The minimum of two critics underestimates on purpose.
Undirected exploration
Entropy is not curiosity — sparse rewards stay hard.

Scope of this study: one environment, three training seeds per algorithm, fixed — not exhaustively tuned — hyperparameters. The demonstration model was selected after exploration.

Mikhail KrylovFindings18

What we observed

Standard SAC learned locomotion

Standard SAC learned locomotion with the Ant-v5 reward. We used automatic entropy tuning, without adding a custom reward-shaping term or curiosity module.

A walking policy within 1M steps

Our SAC setup used replay and produced a walking policy within this budget. We did not isolate the contribution of replay.

Seed variance is not noise to hide

SAC led on average, but overlapped with TD3 on one run. Three trainings describe these configurations, not a ranking of algorithms.
